# Тихий старт · StartupTidy

**Управление фоновыми приложениями при входе в Windows.**

StartupTidy закрывает выбранные программы в течение заданного времени после входа в систему. Утилита работает в трее, поддерживает групповой выбор процессов, светлую и тёмную мятную темы и локальный журнал. Интерфейс на русском языке.

**Текущая версия: 1.3.1 · Windows 10/11 · C# / WinForms / .NET Framework**

## Скачать и запустить

**[Скачать StartupTidy 1.3.1 — готовый ZIP](https://github.com/digital-drowner/StartupTidy/raw/refs/heads/main/downloads/StartupTidy-1.3.1.zip)** · [Отдельный EXE](https://github.com/digital-drowner/StartupTidy/raw/refs/heads/main/StartupTidy.exe)

1. Распакуй ZIP в постоянную папку и запусти `StartupTidy.exe`.
2. Нажми **«Из запущенных…»** или **«Выбрать .exe…»** и добавь ненужные приложения.
3. Для проверки нажми **«Закрыть сейчас»**. Результат появится в журнале.
4. При необходимости включи **«Запускать при входе в Windows»** в настройках.

Установщик, Python и сторонние пакеты не нужны. Требуется установленный .NET Framework 4.x. Права администратора для обычного запуска не требуются. EXE не подписан цифровой подписью.

## Возможности

- **Наблюдение после входа:** по умолчанию 3 минуты, проверка каждые 10 секунд. Интервал и длительность настраиваются; доступен постоянный режим.
- **Новые процессы без повторов:** окно добавления скрывает EXE, уже присутствующие в любых правилах. Остальные процессы видны, включая важные и недоступные для чтения пути.
- **Важные процессы:** отдельный раздел, предупреждение, явное разрешение на закрытие и возможность его отозвать.
- **Точный выбор:** приложения сопоставляются по полному пути к EXE, а не только по имени.
- **Групповые действия:** Ctrl + щелчок, Shift + щелчок и Ctrl + A; пакетное добавление, включение, выключение, удаление правил и изменение способа закрытия.
- **Два способа закрытия:** обычное закрытие окна либо принудительное завершение, разрешённое отдельно для выбранных программ.
- **Понятный статус:** серый значок в трее — наблюдение остановлено; зелёный с галочкой — активно.
- **Две темы:** светлая и тёмная с мятными акцентами. Выбор сохраняется сразу.
- **Локальный журнал:** результаты закрытия и ошибки доступны в интерфейсе и файлах журнала.

Крестик сворачивает окно в трей. Для полного завершения выбери **«Выход»**.

## Как работает закрытие

Обычный режим отправляет запрос главному окну приложения и ждёт до 3 секунд. Фоновый процесс без доступного окна может остаться работать. Если для правила разрешено принудительное завершение, утилита завершит процесс, когда обычное закрытие не помогло. **При этом возможна потеря несохранённых данных.** По умолчанию принудительное завершение выключено.

Обычные правила работают с доступными процессами текущего пользователя и сеанса Windows. Процессы из папки Windows, известные системные и защитные приложения, а также процессы с другим или непроверенным владельцем показываются и помечаются важными. Такие правила добавляются выключенными; для включения нужно подтвердить предупреждение. Разрешение действует и при следующих запусках, для всех доступных экземпляров выбранного EXE. Через меню «Важные процессы…» разрешение можно отозвать. Саму утилиту закрывать через собственный список нельзя.

Если Windows не раскрывает путь, процесс остаётся виден, но создать надёжное правило по имени или PID нельзя. Подтверждение не обходит ограничения доступа Windows и не повышает права автоматически.

StartupTidy не отключает службы или задания планировщика: сторонняя программа может запуститься снова. В постоянном режиме будут закрываться также приложения, которые пользователь открывает вручную.

## Что нового в 1.3.1

- Скрытие уже добавленных EXE по полному пути во всех разделах, включая выключенные и важные правила.
- Остальные процессы видны без скрытия по владельцу, папке Windows или известному имени.
- Разделы «Все правила», «Обычные программы» и «Важные процессы — с предупреждением».
- Важные правила выключены до подтверждения; разрешение можно отозвать.
- Недоступные пути явно отмечены, а повторные PID одного EXE создают одно правило.

## Данные и обновление

Правила, выбранная тема и журнал хранятся в `%LOCALAPPDATA%\StartupTidy`. Утилита работает локально и не отправляет их в интернет.

Для обновления выйди через **«Выход»** и замени EXE в той же папке. Настройки сохранятся. Если перемещаешь приложение, заново включи автозапуск из нового расположения.

## Сборка и тесты

Запусти `BUILD.cmd` из корня репозитория. Скрипт использует компилятор .NET Framework из папки Windows и создаёт `StartupTidy.exe`. Внешние зависимости не скачиваются. Значки встроены в EXE.

Для проверок запусти `tests\RUN-TESTS.cmd`. Тесты используют собственные процессы и изолированные настройки; временные результаты сохраняются в `tests/scratch`.

Для версии 1.3.1 пройдены **117 автоматических проверок**, включая закрытие тестовых процессов, повторное открытие заполненного списка, групповые действия, переключение значков и темы, выравнивание кнопок, отрисовку прокрутки, полный список процессов и разрешения для важных правил. Проверка реальной перезагрузки и физического перетаскивания полосы прокрутки не выполнялась. Подробности — в [отчёте о проверках](docs/VERIFICATION.md).
