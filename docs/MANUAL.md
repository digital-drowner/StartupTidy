# Тихий старт · StartupTidy 1.2.1

Локальная утилита для Windows 10/11: закрывает выбранные приложения после входа в систему. Интерфейс на русском, значок в трее, журнал и настройки. Сеть, аккаунт, Python и установка дополнительных пакетов не нужны. Используется .NET Framework 4.x, присутствующий на компьютере, где собрана эта версия. Запускать от администратора не требуется.

## Быстрый запуск

1. Если используешь ZIP, **сначала распакуй его** в постоянную папку, например `Документы\StartupTidy`. Не запускай программу прямо из ZIP.
2. Открой **StartupTidy.exe**.
3. На вкладке «Программы» нажми **«Из запущенных…»** или **«Выбрать .exe…»**. Выбери ненужное приложение. Правило включается галочкой и сохраняется сразу; удаление и изменение способа закрытия также сохраняются сразу.
4. Для первой проверки нажми **«Закрыть сейчас»**. Результат появится на вкладке «Журнал».
5. Для фоновой программы без окна выбери её в списке, нажми **«Способ закрытия…»** и при необходимости разреши принудительное завершение. Оно может привести к потере несохранённых данных.
6. На вкладке «Настройки» включи **«Запускать при входе в Windows»** и нажми **«Применить настройки»**. Оставь папку с EXE на этом месте.

При обычном ручном запуске наблюдение остановлено до нажатия «Начать наблюдение». При входе в Windows утилита запускается в трее и сама начинает наблюдение. По умолчанию проверяет процессы раз в 10 секунд в течение 3 минут **с момента своего запуска**. После истечения времени закрытие прекращается; значок остаётся в трее для доступа к настройкам. Длительность и интервал можно изменить.

«Закрыть сейчас» выполняет один проход по включённым правилам. «Начать наблюдение» запускает повторные проверки. Неудачный запрос закрытия одного и того же экземпляра приложения повторяется не чаще раза в минуту. Новый экземпляр процесса проверяется заново.

## Как закрываются программы

- Сопоставляется **полный путь к .exe**, без учёта регистра. Просто совпадающего имени недостаточно. Все доступные экземпляры выбранного EXE в текущем сеансе пользователя могут быть закрыты.
- Утилита сначала отправляет запрос обычного закрытия главному окну приложения. Она не нажимает кнопки «Сохранить» / «Не сохранять» в появившихся диалогах.
- Если включено принудительное завершение, после ожидания до 3 секунд процесс завершается. У процесса без доступного окна ожидания нет.
- По умолчанию принудительное завершение **выключено для каждой новой программы**. Фоновый процесс без окна в обычном режиме останется работать; это будет записано в журнал.
- Закрываются только доступные процессы того же пользователя Windows и того же сеанса. Другие пользователи, системные службы, процессы из папки Windows, сама утилита и несколько известных системных/защитных процессов исключены. Это не полный каталог всех важных программ: список приложений выбираешь ты.
- Утилита не повышает права. Процесс с более высокими правами может остаться открытым с записью об ошибке.
- Службы и задания планировщика не отключаются. Если программа постоянно запускается снова, лучше найти её источник запуска. Постоянное наблюдение доступно как отдельная настройка; оно закроет также программы, которые ты открываешь вручную.

## Трей, настройки и удаление

Крестик окна **сворачивает утилиту в трей**. Двойной щелчок по значку открывает окно. В меню значка доступны начало и остановка наблюдения, настройки и выход. Кнопка «Выход» полностью завершает программу. Если при повторном запуске появится сообщение, что утилита уже работает, найди её значок возле часов, в том числе среди скрытых значков.

Чтобы убрать утилиту: выключи автозапуск → «Применить настройки» → «Выход» → удали папку программы. Если папку нужно переместить, сначала выключи автозапуск, а затем включи его из нового расположения. Автозапуск хранится только для текущего пользователя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `StartupTidy`.

Данные находятся в `%LOCALAPPDATA%\StartupTidy`:

- `config.json` — правила и параметры;
- `config.json.bak` — предыдущая версия настроек;
- `journal.log` и `journal.log.1` — локальный журнал; около 1 МБ на файл, возможен небольшой выход за порог на размер одной записи.

На вкладке «Журнал» есть кнопка открытия папки данных. Журнал содержит пути выбранных приложений и ошибки закрытия. Ничего не отправляется в интернет. Данные можно удалить вручную после выхода из утилиты; при следующем запуске будет пустой список. Если JSON повреждён, утилита показывает ошибку и не начинает наблюдение автоматически.

## Исходный код и сборка

`StartupTidy.cs` — весь код; `app.manifest` — запуск без повышения прав и поддержка DPI; `BUILD.cmd` — пересборка встроенным компилятором .NET Framework. Перед пересборкой выйди из утилиты, затем запусти `BUILD.cmd`. Компилятор не скачивается. Готовый EXE не подписан цифровой подписью.

Тесты интерфейса используют отдельную папку данных и подменённое чтение автозапуска: реестр и пользовательские правила не изменяются. Тестовые исходники находятся в `tests`, запуск — `tests\RUN-TESTS.cmd`. Они создают собственные временные процессы, проверяют закрытие только этих процессов и сохраняют тестовые файлы в `tests\scratch`. Пользовательские правила и автозапуск тесты не меняют.

## Обновление с 1.0 до 1.0.1

В диалоге ошибки старой версии нажми «Выход». Если утилита осталась в трее — выбери «Выход» в её меню. Замени `StartupTidy.exe` в прежней папке новым EXE из архива 1.0.1 и запусти его. Правила хранятся отдельно в `%LOCALAPPDATA%\StartupTidy` и при замене EXE сохраняются; удалять `config.json` не нужно. Если путь к EXE не меняется, запись автозапуска также остаётся прежней.

В 1.0.1 исправлена ошибка `NullReferenceException` при повторном открытии уже заполненного списка. Обработчик галочек больше не принимает служебные уведомления Windows за пользовательские изменения и не перебирает временные строки без привязанного правила.

## Групповой выбор — версия 1.1.0

В окне «Из запущенных…» и основном списке работает стандартное выделение Windows: **Ctrl + левый щелчок** выбирает отдельные строки, **Shift + левый щелчок** выбирает диапазон, **Ctrl + A** выбирает всё. Щёлкай по названию или строке; галочка слева включает само правило.

В окне выбора нажми «Добавить выбранные»: добавятся все выделенные приложения. В диалоге выбора EXE также можно выбрать несколько файлов. Дубликаты пропускаются, проблемы добавления показываются одним сообщением. Новые программы автоматически выделяются в основном списке для дальнейшего редактирования.

В основном списке выдели нужные программы и нажми «Способ закрытия…». Одна галочка в диалоге задаёт принудительное завершение всем выделенным приложениям. Если способы различаются, первоначально показана промежуточная галочка — она означает «оставить прежние значения». Можно задать всем включённое или выключенное принудительное завершение. Настройки остальных строк не меняются. Кнопки «Включить выбранные», «Выключить выбранные» и «Удалить выбранные» также применяются ко всему выделению; удаление убирает правила из списка, а не файлы приложений.

Для обновления выйди из утилиты через «Выход» и замени EXE в прежней папке файлом из архива 1.1.0. Путь к настройкам и формат JSON прежние; список программ сохраняется.

## Значки — версия 1.1.1

Использованы предоставленные пользователем `app.ico`, `tray-inactive.ico` и `tray-active.ico`. Основной значок встроен в ресурсы EXE для Проводника и используется в окне программы. Серый значок в трее означает, что наблюдение остановлено. Зелёный с галочкой означает, что наблюдение включено, включая промежутки между проверками. После ручной остановки или истечения времени значок снова серый. Однократная команда «Закрыть сейчас» не включает режим наблюдения.

Все значки встроены внутрь EXE. Для запуска достаточно одного `StartupTidy.exe`; папка `assets` нужна только для пересборки из исходников. Для обновления выйди из утилиты через «Выход» и замени EXE в прежней папке файлом версии 1.1.1. Настройки и путь к ним прежние. Windows может некоторое время показывать старый значок файла из своего кэша; значок трея берётся непосредственно из новой программы.

## Светлая и тёмная темы — версия 1.2.0

Открой «Настройки» и переключи **«Тёмная тема — тёмный фон и мятные акценты»**. Тема меняется сразу и сохраняется автоматически: нажимать «Применить настройки» для неё не требуется. Снять галочку — вернуться к светлой теме. Старые настройки без поля DarkTheme открываются в светлой теме.

Тёмная тема использует сине-серый фон (#121D27), панели (#192734) и мятные акценты (#5EE2BC) в духе значка. Оформлены главное окно, вкладки, строки и выделение списка, журнал, меню трея, выбор процессов и диалог способа закрытия. Системные диалоги выбора файла и сообщения Windows могут использовать системное оформление. Тёмная строка заголовка запрашивается через Windows DWM, её вид зависит от Windows.

Переключение не меняет список, настройки закрытия, выделение и статус наблюдения. Для обновления выйди из утилиты через «Выход» и замени EXE в прежней папке новым файлом из архива 1.2.0. Для пересборки добавлен файл Theme.cs; все ресурсы по-прежнему встроены в EXE.

## Исправления оформления — версия 1.2.1

У нижних кнопок одинаковые верхние отступы и минимальная высота: «Начать наблюдение», «Закрыть сейчас» и «Выход» стоят на одной линии. Для полос прокрутки списков в тёмной теме добавлена собственная отрисовка неклиентской области: тёмная дорожка, серый ползунок, мятные стрелки. Нативные механизмы прокрутки Windows сохранены. При возврате в светлую тему используется обычное системное оформление.

Для обновления выбери «Выход» и замени EXE в прежней папке файлом из архива 1.2.1. Список и выбранная тема сохранятся.
